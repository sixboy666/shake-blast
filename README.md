# SHAKE BLAST: FIZZ LAWSUIT

Small shake. Universal consequences. A music-first brainrot meme game where you tap beats to build fizz pressure, then blast the cap off and trigger absurd universe-scale lawsuit events.

- 100% single-file HTML5, zero dependencies, zero loaded files - every sound is synthesized live with Web Audio
- Tap 8 shake beats on rhythm to build fizz pressure, then hit beat 9 to BLAST the cap off
- Tiny shake triggers absurd universe-scale consequence cards (lawsuits, chaos, mult bonuses)
- 5 switchable scenes: THE KITCHEN, NEON ROOFTOP, OHIO MALL, THE COURT, THE VOID
- 7-state emotion machine on the bottle face: idle, focus, happy, wow, panic, shock, dead
- Autonomous blink, breathing squash-and-stretch, pupil tracking toward your pointer
- Original 32-step lead hook (A-pentatonic square + triangle octave sparkle), kick/hat/snare/bass, riser into blast crash
- BPM escalates each level (120 to 156), perfect/good/weak/miss timing windows
- Phone (tap) and desktop (click / space / enter / arrow-up), keys 1-5 switch scenes
- Best score saved locally; 10-30 second rounds; escalating chaos

## Play
- Online: https://sixboy666.github.io/shake-blast/
- Offline: download shake-blast.zip from Releases, unzip, open index.html
